# KUEM GUI suggestions

Six high-fidelity desktop homepage directions generated from the current KUEM site content and informed by the Impeccable and UI/UX Pro Max design skills.

1. `01-editorial-technology.png` — bold European editorial layout with engineered linework.
2. `02-swiss-technical.png` — strict Swiss grid, direct service bands, and factual engineering principles.
3. `03-dark-systems.png` — premium dark technical observatory centered on system integration.
4. `04-warm-human.png` — human-centered consultancy direction with documentary imagery and verified KUEM contact details.
5. `05-industrial-blueprint.png` — industrial blueprint language that visualizes KUEM's layered engineering offer.
6. `06-data-led-narrative.png` — information-design direction built around Discover, Design, Deliver, Evolve.

These PNGs are visual proposals, not final production screens. Validate all copy and partner-mark usage before implementation. Concepts 1, 3, 5, and 6 may contain illustrative or AI-rendered logo treatments; concepts 2 and 4 use partner names as text to reduce that ambiguity.

Shared prompt intent: create a shippable, accessible 16:9 desktop KUEM homepage using the real service areas (software development, architecture and consulting, DevOps and platforms), Nexavia, partner trust, and a clear contact action. Each direction was constrained to avoid generic SaaS card walls, purple gradients, gratuitous glassmorphism, excessive pills, emoji icons, and illegible microcopy.

Generation mode: built-in image generation.
