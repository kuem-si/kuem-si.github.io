Official Nexavia SVG artwork supplied by KUEM.

The original six SVG files are preserved unchanged. `NEXAVIA-web-Black.svg`
and `NEXAVIA-web-White.svg` use the corresponding positive artwork with only
the SVG viewBox adjusted to remove excess canvas space. Paths, proportions
and colors are unchanged. Use Black on light backgrounds and White on dark
backgrounds. The Nexavia favicon is available here for Nexavia-specific
applications; the KUEM website retains its KUEM favicon.
