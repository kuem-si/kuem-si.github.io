# KAI logo

`kai-lockup-endorsed-on-dark.svg` is the approved KAI lockup ("KAI by KUEM") for dark backgrounds, copied unchanged from `kuem-si/kai-brand-assets` at release `identity-v1.5.0` (commit `185e0a7`), `logos/svg/kai-lockup-endorsed-on-dark.svg`. Do not edit it; replace it from a later KAI release.

It is used only on dark (`carbon`) surfaces, at least 72 px wide, with clear space equal to the radius of the solid circle in the mark.
